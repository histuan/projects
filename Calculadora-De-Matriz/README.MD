# Calculadora de Sistemas Lineares
capaz de calcular matrizes e vetores.

### realiza:
- soma.
- multiplicação.
- transposição.
- eliminação de gauss.
- resolução de sistemas.

### possui:
- tratamentos de erro.
- funções explicadas com comentarios.
- menu interativo.
- 5 classes diferentes.
- livre navegação entre tipos de operações.

feito em java.
