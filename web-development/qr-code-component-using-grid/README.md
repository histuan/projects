# QR Code Component

A QR code card built with HTML and CSS, laid out with CSS Grid.

This is my solution to the QR code component challenge from [Frontend Mentor](https://www.frontendmentor.io/).

Live version: https://histuan.github.io/projects/web-development/qr-code-component-using-grid/

## How to run

Open `index.html` in a browser.
