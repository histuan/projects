# Frontend Mentor - FAQ accordion

This is my solution to the FAQ accordion challenge from [Frontend Mentor](https://www.frontendmentor.io/).

### Technologies used:
- JavaScript
- HTML
- CSS

A responsive and interactive FAQ page. It uses JavaScript to toggle the answers and CSS for smooth transition animations.

Live version: https://histuan.github.io/projects/web-development/faq-accordion-main/


## How to run

Open `index.html` in a browser.
