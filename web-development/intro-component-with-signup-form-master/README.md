# Frontend Mentor - Intro component with sign up form

This is my solution to the sign up form challenge from [Frontend Mentor](https://www.frontendmentor.io/).

### Technologies used: 
- JavaScript
- HTML
- CSS

A responsive sign-up page featuring custom form validation. It includes two approaches: a basic version modifying native HTML validation, and a main version that replaces it entirely with custom JavaScript logic, styling, and error messages.

Live version: https://histuan.github.io/projects/web-development/intro-component-with-signup-form-master/

## How to run

Open `index.html` in a browser.
